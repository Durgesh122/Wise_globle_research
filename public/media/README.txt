Place your media files here so they are served at /media/...

Examples:
- intro.mp4       -> available at https://<your-domain>/media/intro.mp4
- intro.vtt       -> available at https://<your-domain>/media/intro.vtt (captions)
- poster.jpg      -> available at https://<your-domain>/media/poster.jpg (optional poster)

Notes:
- Filenames are case-sensitive on some hosts.
- For accessibility, include a WebVTT captions file (.vtt).
- Use only content you own or that has an appropriate license (Public Domain/CC0/stock with commercial license).
